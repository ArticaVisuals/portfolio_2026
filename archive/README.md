# Portfolio 2026 Archive

This is the single archive for retired, historical, local-only, and generated
reference material that should not sit in the active Framer working surface.
The former `_archive/` tree was merged here on 2026-07-22 without overwriting
any files.

## Folders

- `cargo-era/` — retired Cargo-site media and route scrapes.
- `retired-framer-routes/` — media from Framer routes that are no longer active.
- `info-page-backups/` — dated Info-page snapshots and prototypes.
- `generated-artifacts/` — preserved browser QA (`browser-qa/`), screenshots
  and site checks (`site-qa/`), contact sheets, and media audits (`media-qa/`)
  formerly stored in `output/`. Cross-project media batch records now live in
  `generated-artifacts/media-optimization/`; their reusable files live under
  `assets/by-project/` or `assets/Play/`, according to site section.
- `local-only-drafts/` — TSX drafts/helpers that are not current Framer code.
- `retired-play-helpers-2026-06-18/` — self-contained rollback package for the
  retired `/play` helper stack.
- `bundled-framer-app/` — minified Framer/Electron application artifacts, not
  portfolio source.
- `handoffs/` — one-off handoff notes whose durable information has been folded
  into current project docs.
- `misc/` — unattributed archived material.

Some archived files have identical bytes by design. The Cargo `/projects` and
`/mini-projects` scrapes, retired Framer route snapshots, and dated Info-page
snapshots retain separate files because their route-specific manifests and
snapshot names preserve provenance. Do not deduplicate those paths without
normalizing their manifests first.

Do not treat anything here as deleted from Framer. This archive is only a local
workspace organization layer.
