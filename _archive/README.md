# Portfolio 2026 Archive

This folder holds retired or local-only material that should stay available for
reference but should not sit in the active Framer working surface.

## Folders

- `local-only-drafts/` - local TSX drafts/helpers that are not current Framer
  code files.
- `bundled-framer-app/` - minified/bundled Framer/Electron app artifacts, not
  portfolio source.
- `handoffs/` - one-off handoff notes whose durable information has been folded
  into current project docs.

Do not treat anything here as deleted from Framer. This archive is only a local
workspace organization layer.
