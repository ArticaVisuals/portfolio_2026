Components

Hero

Markdown

The opening of a page. A huge name and descriptor on Home; a bold title continuing in Stroke Gray on case studies.

liveFramer: Home "Header" section (Heading 1 + Heading 3); case-study hero (Heading 2b, two colors)

Examples

Home

Case study

Usage

VariantTitleSupporting textWhere
HomeDisplay XL, bold, the nameHeading, two lines, Forest Green/ only
Case studyDisplay L, bold, project nameSame size and weight, continues in Stroke Gray/case-studies/*
  • Home: the name's line box 90px from the top (97 mobile) under the fixed nav, with a 6px optical overhang to the left (5 tablet, 3 mobile); the descriptor 220 / 186 / 162px from the top, a two-line descriptor at a fixed width (382 / 218 / 181px), then the link row pinned 10px from the bottom of the 100px bottom padding, on the 20px nav gutter. There is no rule here: the rule that follows belongs to the Selected work Section Header.
  • Case study: the project name is the start of a sentence that continues in muted gray: name, then one line of what the project does for people. Up to three lines on desktop. The full-bleed hero media and the Meta Grid follow.
  • Hero copy rises in with the type reveal (900ms, 90ms stagger).

API

Class / attributeNotes
mh-heroColumn stack, 144px top padding
data-variant="case-study"Applies Display L to .mh-hero__name
mh-hero__nameThe h1. Add mh-text-display-xl for Home
mh-hero__descriptorHeading style, max-width: 11em to force the two-line break
mh-hero__continuationMuted continuation inside the case-study h1
mh-hero__barBase row with bottom rule

Accessibility

  • One h1 per page: the name on Home, the project name + continuation on case studies (read as one sentence).
  • Reveal spans don't change reading order.

Framer mapping

  • Home: text styles Heading 1 (name) and Heading 3 (descriptor). Appear effects: name translateY 110px → 0, descriptor 90px → 0, Snappy; replays are coordinated by PageTransition (gmalnRr).
  • Case study: Heading 2b in two text layers (/Forest Green then /Stroke Gray) or one rich-text layer with a color span.

Don't

  • Don't add a hero image to Home; the selected-work grid is the imagery.
  • Don't put a subtitle under a case-study title. The continuation is the subtitle.
