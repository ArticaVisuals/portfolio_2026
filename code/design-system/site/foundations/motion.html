Motion

Markdown

Three curves, a short list of durations, and the two signature moves, the flip rail and the type reveal.

Overview

Motion should feel like the site is alive, not performing. It decelerates into place, moves only a few pixels, and respects prefers-reduced-motion. There are three easing curves, and the first one handles almost everything.

Easing

Click a row to play it at 900ms.

TokenCurveUse
--mh-ease-snappycubic-bezier(0.16, 1, 0.3, 1)Default. Reveals, hover transforms, media scale, fades, page transitions.
--mh-ease-smoothcubic-bezier(0.12, 0.23, 0.5, 1)Symmetric changes: row hover wash, filter color, loader bar.
--mh-ease-springycubic-bezier(0.25, 1, 0.5, 1)Gesture-like only: rule line draw, cursor trails. Never UI state.

Durations

TokenValueUse
--mh-duration-instant150msRow hover wash
--mh-duration-fast250msColor changes (tag hover)
--mh-duration-zoom260msLightbox open / close
--mh-duration-base420msHover transforms: flip rail, media scale
--mh-duration-slow620msIndex flip rail, media fade-in
--mh-duration-reveal900msType reveal; scroll-to-top travel
--mh-duration-page1200msBoot curtain lift, page transition
--mh-duration-draw2000msRule line draw (200ms delay)
--mh-stagger-reveal90msBetween lines in a type reveal
--mh-stagger-media58msBetween thumbnails fading in

Springs

Hovers and reveals use the curves above. Anything the visitor can grab (drag, swipe, sheets) uses spring tokens instead: critically damped by default, bounce only after a throw. See Gesture and Interaction Principles.

TokenDampingResponse
motion.spring.default1.00.4s
motion.spring.quick1.00.3s
motion.spring.momentum0.80.4s

Flip rail

The site's main hover. A label is stacked over a copy of itself in a one-line window; on hover the stack slides up by one line plus --mh-distance-flip-gap (5px). Used on nav links, project titles, index rows and text actions. It works with CSS alone.

Type reveal

Display lines rise into a clipping mask: start at translateY(115%), end at 0, 900ms Snappy, 90ms between lines. Add .mh-reveal per line and set --i for the order; components.js adds .is-in when it enters the viewport.

Hover scale

Media inside a link scales to --mh-scale-hover (1.02) over 420ms Snappy. The frame doesn't move; only the image does, clipped by the frame. See Media Frame.

Usage

  • Default to Snappy + 420ms. Reach for anything else only if the table above says so.
  • Move things a few pixels or one line. Don't fly elements in from off-screen.
  • Animate transform and opacity only.
  • Under prefers-reduced-motion: reduce, transitions collapse to 1ms and reveals render in place (css/base.css).
  • Framer: use the same curves in Appear/Hover effects (Framer "Custom bezier"). Page transitions and the boot curtain belong to PageTransition (gmalnRr); don't build a second transition system.

Don't

  • No bounce, elastic or overshoot curves on UI (the momentum spring is only for thrown gestures).
  • No parallax, scroll-jacking or auto-playing carousels.
  • No looping attention animations on UI (the grain shimmer is the only ambient motion).
