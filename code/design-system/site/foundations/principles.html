Principles

Markdown

Five words that settle design decisions, and the voice the site writes in.

The portfolio presents a brand designer who thinks in systems, with range as the proof. Its main reader is a senior brand or design lead with a high craft bar. The site's job is to make the work easy to read without diluting or over-explaining it.

Five words

PrincipleMeansIn practice
ConsideredEvery element earns its place.No feature because it's cool. If a component isn't on this site, don't add it.
QuietThe work is loud enough. The site doesn't need to be.Cream ground, one green, small mono labels, no decoration. Media carries the color.
AliveSmall, intentional moments of motion and response.Flip-rail hovers, type that rises in, a faint moving grain. Never motion for its own sake.
Specific"I did X", not "we did Y". Credit is precise.Meta grids name the client, role and scope. Copy names real outcomes.
ShippedWork that exists in the world outweighs work that lives in Figma.Lead with launched work; show it in context (product, retail, motion).

Apple's eight design principles map onto these five words. See Interaction Principles for that mapping and for the fluid-interface rules, each labeled as already true, for new work, or a deliberate departure.

What the site is not

  • Not an archive. The Index holds everything; Home shows six projects.
  • Not a UX deep-dive site. Process lives inside individual case studies.
  • Not a template. Nothing should read as a stock portfolio theme.

Voice and copy

  • Plain, first person, present tense. "I'm a brand designer with a systems mind."
  • Short declaratives. Case-study intros chain cause and effect: "A photograph becomes a data point. A data point becomes a record."
  • Title Case only for project names; headings are sentence case ("Selected work", "About Micah").
  • Mono labels are nouns, not sentences: / INDUSTRY, / SCOPE, VIEW ALL, AVAILABLE FOR WORK.
  • The slash is structural. Meta labels start with / and numbered titles read 1 / GAIA.
  • Credits are exact: "Client: Self-Initiated Proposal", "Designer: Micah Hoang".
  • No exclamation marks, no emoji, no "passionate", "innovative", "pixel-perfect".

Decision checklist for agents

  1. Does an existing component or pattern already cover this? Use it.
  2. Does every color, size and duration resolve to a token?
  3. Is there one clear display moment per view, with everything else small?
  4. Would removing this element lose anything? If not, remove it.
  5. Does it work at 390px?
