Introduction

Markdown

The visual foundations, components and page patterns behind micahhoang.com.

This is the design system behind micahhoang.com: the foundations every page is built on, the components the site is made of, and the page patterns that put them together. It describes what is live today, measured from the published site, and maps each piece back to its Framer style or code component.

Foundations define the tokens for color, type, layout, motion, texture and identity. Components go from small pieces like the Mono Label and Tag up to the Project Card, Index List and Footer. Patterns show how the Home, Case Study and Index pages are put together. Each component page has live examples, usage rules, the class API and its Framer mapping.

Pick a page from the sidebar, or press ⌘K to search. Every page also exists as markdown for agents: use the Markdown link in its header, or start from agents.md.

The system at a glance

Principles

Five words to go back to whenever a decision is unclear: Considered. Quiet. Alive. Specific. Shipped. Read Principles before designing anything new.

Start here

  • Colors: two surfaces (Cream and Forest Green) and semantic roles.
  • Typography: GT Standard for display and body, GT Standard Mono for labels.
  • Layout: gutters, grids, breakpoints, rules instead of boxes.
  • Motion: the Snappy ease, flip rails and type reveals.
  • Project Card: the main way work appears on the site.
  • Case Study pattern: the template every project page follows.
