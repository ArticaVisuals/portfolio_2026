Hi everyone,

In our 45-minute workshop, we’ll build a portfolio reviewer that understands your work and a job you’re interested in. Then we’ll use the same context to practice an interview question aloud, get feedback, and try again.

Please prepare before class:

- Read the attached prep PDF. It explains what to bring and the exact filenames we’ll use in the copyable prompts.
- Download and unzip portfolio-brain-starter.zip. Add your resume, one portfolio case study, project-role notes, existing reflections, relationship map, and one complete job description to the folders shown in the guide.
- Test Claude Code and regular Claude voice. Bring your laptop, charger, and headphones with a microphone.

The starter already includes the IBM CDO design-team interview question guide and a readable question bank. Our coach will mix these educational examples with questions tailored to your target job. No need to transcribe the questions or prepare answers in advance.

Use the homework you’ve already done; you don’t need to write a new reflection. We’ll create ICP.md and the skills together in class.

If you run into setup or file-preparation issues, comment here before class so we can sort them out.

See you there,
