# Portfolio Brain Workshop Starter

1. Add your own files to sources/ and targets/ using the prep guide filenames.
2. Keep references/ and CLAUDE.md in this folder. The shared interview question bank is already included.
3. Before class, test opening this entire portfolio-brain folder in Claude Code, and test voice in a regular Claude chat.
4. In class, use WORKSHOP-PROMPTS.md. We will build your ICP and skills together.

The original IBM CDO question guide and its readable question bank are included for educational use, with attribution. You do not need to transcribe them, create a skill for them, or prepare answers before class. Every new mock starts with a simulated interviewer introduction and “Tell me about yourself,” followed by coaching and a retry. The coach then chooses relevant bank examples, job-specific questions, and follow-ups with no fixed question cap.

No candidate data is included in this starter. Do not rename someone else's demo files and pass them off as your experience.

Adaptive practice: say “continue,” “retry,” or “new round.” Extra jobs are optional; the original single-job pre-work still works. Follow the updated WORKSHOP-PROMPTS.md; no folder migration is needed. In a voice chat, share a new job description or brief to switch roles.
